# MAJE Enterprise Document Registry

---

# Purpose

Dokumen ini mendefinisikan seluruh jenis dokumen resmi yang digunakan dalam proyek MAJE.

Seluruh dokumentasi harus menggunakan salah satu prefix yang terdaftar di dokumen ini.

---

# Document Prefix Registry

| Prefix | Name | Description |
|---------|------|-------------|
| ARC | Architecture | Enterprise Architecture Documents |
| HC | Hardy Chung Governance Series | Enterprise Governance Documents |
| PRD | Product | Product Management Documents |
| DB | Database | Database Documentation |
| API | API Specification | API & Integration Documents |
| OPS | Operations | Operations & Production Documents |
| STD | Standard | Engineering Standards |
| ADR | Architecture Decision Record | Architecture Decisions |
| TPL | Template | Documentation Templates |
| GEN | Generated | Generated Documents |

---

# Prefix Rules

- Satu dokumen hanya boleh memiliki satu prefix.
- Prefix tidak boleh diubah setelah dipublikasikan.
- Nomor dokumen harus unik.
- Dokumen baru harus terdaftar pada registry ini.

---

# Numbering Convention

Contoh:

```
ARC-001

ARC-002

HC-001

HC-002

PRD-001

DB-001

API-001
```

Nomor tidak boleh digunakan ulang.

---

# Versioning

Seluruh dokumen wajib memiliki:

- Version
- Status
- Revision History

---

# Repository

Seluruh dokumen resmi disimpan di repository Git MAJE.

Repository merupakan satu-satunya sumber dokumentasi resmi.
