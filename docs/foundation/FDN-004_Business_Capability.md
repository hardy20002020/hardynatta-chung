# 1. Purpose

FDN-004 mendefinisikan **Business Capability Model** HARDYNATTA CHUNG Enterprise Software Engineering Ecosystem.

Business Capability menjelaskan **kemampuan apa yang harus dimiliki enterprise** untuk mewujudkan vision, mission, principles, dan platform secara berkelanjutan.

Capability bukan daftar fitur.

Capability bukan daftar jabatan.

Capability bukan daftar software.

Capability adalah kemampuan organisasi yang memungkinkan enterprise menghasilkan value secara konsisten.

---

# 2. Capability Definition

Business Capability dapat dirumuskan sebagai:

> **The ability of an enterprise to perform a business function and consistently produce an intended outcome.**

Dalam konteks HARDYNATTA CHUNG:

> **Business Capability adalah kemampuan yang memungkinkan ecosystem mengubah pengalaman, pengetahuan, standar, teknologi, dan sumber daya manusia menjadi platform dan value yang berkelanjutan.**

5. Capability Principle

Capability model mengikuti prinsip:

Capability defines what the enterprise must be able to do, not how a specific technology performs it.

Karena itu:

Capability
    ≠
Technology

dan:

Capability
    ≠
Current Implementation

Teknologi dapat berubah tanpa mengubah capability yang mendasarinya.

22. Capability Maturity

Capability dapat berkembang melalui maturity levels:

Level	Name	Description
0	Nonexistent	Capability belum tersedia
1	Initial	Capability tersedia secara ad hoc
2	Repeatable	Capability mulai dapat diulang
3	Defined	Capability memiliki process dan standard
4	Managed	Capability diukur dan dikendalikan
5	Optimized	Capability terus ditingkatkan berdasarkan evidence
