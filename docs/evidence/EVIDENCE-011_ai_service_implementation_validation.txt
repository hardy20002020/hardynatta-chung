2. AI Service Boundary

backend/app/ai/service.py provides the controlled AIService
application boundary.

The service:

- checks whether AI is enabled;
- rejects empty prompts;
- enforces the configured maximum prompt length;
- invokes the configured model gateway;
- preserves gateway timeout semantics;
- converts unexpected gateway failures into controlled AI errors;
- validates gateway output.

Result:

PASS

3. Model Gateway Abstraction

backend/app/ai/gateway.py provides the ModelGateway abstraction between
application-level AI orchestration and model-provider interaction.

The implementation includes:

- ModelGateway abstract interface;
- DeterministicModelGateway;
- create_model_gateway() factory.

The ModelGateway contract prevents direct instantiation of the abstract
gateway.

The deterministic gateway provides a controlled development and testing
implementation without invoking an external model provider.

Result:

PASS
