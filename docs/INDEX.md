# 11. Repository Authority

The Git repository is the authoritative source for the current MAJE documentation baseline.

Documents must:

- use an approved document identifier;
- follow the applicable documentation governance;
- maintain version and status information where required;
- preserve revision history;
- remain traceable through the documentation structure.

# 12. Maintenance

This index must be updated when:

- a new controlled document is published;
- an existing controlled document is renamed or replaced;
- a document is retired;
- a new documentation domain is introduced;
- document governance changes the official structure.
